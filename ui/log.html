这一页是什么

字段与缺口

时间线按真实落盘记录排开；本场进行中时会持续接上新事件，不必整页刷新。没记录的字段照实标缺失。

日志里已有 缺失已标明 本页无示例数据

左右两条独立轨道

左边是智能对话中枢与 Agent 结果：原话、判停、判答、工具披露、Agent 对话与办理回执。右边是读心输出与画面。两边各自按自己的发生时间挂到中轴上，不是一句话左右对齐。

读心可以先于判停出现，也可以在一句话里更新多次，也可以只有读心没有办理；办理出现时，右侧不一定有新的读心。对侧空着是正常的，不会为了对齐补空白卡片。

画面默认收起

读心文字照常留在时间线上；每一帧画面默认不加载，点「展开画面」才显示这一帧，再点「收起画面」收回去。会话帧多时也可以一次展开或收起全部画面，不会一进日志页就铺满图。

对话可以单独打开

顶栏「打开对话」只把这一场里人对车说的和车上对人说的按发生时间从上往下排开，进行中的场次会顺着往下长。读心画面、判停分数、工具细节不插进这段对话，仍留在时间线按需看。

默认只看结论

每条默认只显示关键结果和一行原因；分数、候选工具、原始事件和关联键都要点开才看。

缺失会标明，不补造

  • 没有判停、判答、工具披露、Agent 对话、读心或画面：照实标「未记录」，不编时间、不拿示例图顶上。
  • 页面那一拍「要不要回答」只作记录，以主链的判答为准；两者都显示，不混成一个。
  • 这一页不提供全文检索、长期保留、权限和跨会话平台；没有做的能力不画成已实现。

本页也可以开整条链路

点「开始本场」走与内心戏同一条开闸 / 选工具 / 办理 / 回话链路（文字验证：发送即收住）。从内心戏换到这里，只要没点停止，场次还在，对话会接上并继续往下长。只有点「停止本场」才结束。
