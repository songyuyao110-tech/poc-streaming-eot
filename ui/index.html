四处出声口径（期五 · 一屏看全）
        同一时刻最多一句 · 出声后 1 秒内不再出声 · 垫句优先于应声 · 有人说话 → 应声 / 垫句；没人说话 → 冷场 · 两人同时说只在「正在说 / 正在准备说」（垫句那一小段也算，应一声不算）

      

        
出声何时问谁优先出声之后

        
          
垫一句（含垫句抢回）
            人还在说、节奏=积极、这一句已连续说满 1.5 秒
            1（最高）：与应声同刻只出垫句
            记住（进本席上下文）；不进 Agent、不选工具、不开闸

          
应一声
            人还在说、这句还没说完（三个等待档里），同一版字上的判断说可以
            2：同刻让位给垫句
            不记住（连上下文也不进）；不开闸、不进 Agent

          
两人同时说
            只在那两个入口：①正在准备说 / 正在回答；②正在说一句垫句。应一声不算
            不跟另三句抢「谁出声」：它只定插话去哪；四条出口里的「垫句抢回」仍受同刻一句约束
            让路=作废本轮（正在准备说）/ 停下这句垫句（正在说垫句），话都留下；说完再接 / 垫句抢回=插话排队随后回答；继续说=只进旁听；都不开闸

          
冷场开口
            只在中枢最后一句说完后安静到刻度（约 4 秒 / 10 秒 / 之后每 8 秒），且真的没人说话
            与应声 / 垫句互斥：有人在说就不会问；安静时也不会再应声 / 垫一句
            记住（进本席上下文），只接上文；不进 Agent、不选工具、不开闸
